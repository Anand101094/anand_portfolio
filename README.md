## 🚀 Standout Features &amp; Interactivity

1. **💊 Red Pill vs. Blue Pill Reality Engine**
   - **RED PILL (Matrix Cyber Experience)**: Authentic digital rain cascade, CRT scanlines, phosphor emerald glow, decrypted Katakana telemetry, and cyberpunk CLI.
   - **BLUE PILL (Silicon Valley Minimalist Mode)**: Instant 0.35s digital warp transition to a clean, modern executive portfolio with obsidian surfaces, electric mint typography, and distraction-free corporate layout for recruiters who prefer a minimalist tech company interface.

2. **⚡ Live Pub/Sub Architecture &amp; Data Flow Bus Simulator**
   - Interactive live circuit visualizing the distributed frontend architecture Anand engineered at T-Mobile (managing 20+ micro-repos) and OpenText (Kafka event streaming).
   - Click **"PULSE DATA PACKET"** to watch animated data telemetry travel from `AEM Authoring` ➔ `Pub/Sub Event Bus` ➔ `Cart & Checkout Engine` ➔ `Kafka Hub` ➔ `GraphQL Gateway`.
   - Click individual nodes for live architectural diagnostics.

3. **📅 Component Lab: Reusable Vanilla JS + JSX Date Range Picker Demo**
   - Live hands-on demonstration of the custom component Anand built for T-Mobile (+15% checkout velocity, zero 200KB bundle bloat from heavyweight libraries).
   - Test preset chips (Last 14 Days, Current Sprint, Q4 Release) and inspect the architectural decision log.

4. **◈ Refined Thematic Cyber Separators**
   - Cleaned of repetitive comment-style `//` dividers. Replaced with purposeful, high-tech tokens:
     - `◈` (Data Diamond Node)
     - `::` (Scope Resolution Operator)
     - `•` (Glowing Matrix Bit)
     - `▸` (Data Stream Vector)

5. **Terminal CLI Drawer (Press `T` or `~`)**
   - Interactive hacker terminal with autocompletion and quick command chips (`help`, `overview`, `exp`, `projects`, `skills`, `contact`, `reality`, `matrix`, `theme`, `sudo hire`).

6. **Web Audio Retro Synthesizer**
   - Zero-dependency tactile audio feedback for clicks, keystrokes, and reality glitch transitions (muted by default; easily enabled via topbar `SOUND: ON`).

7. **Executive Resume PDF Export**
   - Click **"EXPORT RESUME"** to print or save a clean, ATS-compliant executive PDF.
