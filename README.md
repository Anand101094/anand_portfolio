1. **Ambient 3D Matrix Digital Rain Canvas**
   - High-performance phosphor green rain cascading behind content with trailing phosphor decay.

   - Headings, badges, and project titles automatically scramble through Matrix half-width Katakana and hex runes before settling on the real text.

   - Seamless instant view transitions:
     - `[01 // OVERVIEW]` — Identity dossier, core impact metrics (7+ yrs, 20+ repos, 25% speed gain, 20K+ users).
     - `[02 // EXPERIENCE]` — 7+ year chronological data bus (OpenText, HCLTech for T-Mobile, Kaleyra, Software AG, Tech Mahindra).

     - `[06 // TRANSMIT]` — Encrypted packet contact dispatch, one-click email/phone copying, and LinkedIn handshake.

4. **Deep-Dive Project Inspector Modal**
   - Click `INSPECT` on any project to open full architectural specs, challenges solved, key contributions, and operational metrics.

5. **Integrated Matrix CLI Terminal (`Ctrl + ~` or press `T`)**
   - Toggleable cyber terminal drawer with quick command chips:
     - `help` — List available commands

     - `theme <green|cyan|crimson|amber|mono>` — Shift color subroutines
